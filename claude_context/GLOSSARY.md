# Glossary

- **Interaction**: Discord event object passed to a slash command or component callback; carries user, guild, channel and response/followup APIs.
- **CommandTree**: `discord.py` registry used by `main.py` to define and sync slash commands.
- **View**: Discord UI container holding buttons/selects and their callbacks; examples include `ProfileView`, `ConfigMenuView`, `JoinSprintView` and project Views.
- **Modal**: Discord form UI submitted through `on_submit`; `SprintCreateModal` and `WriterBotImportModal` are examples.
- **Callback**: Function registered for a Discord event/component and invoked by the framework after user action.
- **Embed**: Structured Discord message payload built by helpers such as `create_profile_embed()` and sprint message functions.
- **Coroutine**: Awaitable function produced by `async def`; Discord callbacks and API calls are coroutines here.
- **Sprint**: Timed productivity session represented by runtime objects and a persisted recovery record.
- **SprintUser**: Per-participant object containing user/project/counting state and activity history.
- **SprintParticipants**: Collection object that adds, removes and queries `SprintUser` objects.
- **Project**: JSON dictionary with `project_id`, name, description, status, wordcount, goal and creation date.
- **Word Count**: Starting/final total used to calculate positive progress and update a project.
- **Profile**: User JSON record containing XP, level, last project, imports and economy.
- **XP**: Global progression value stored in a profile; current level calculation lives in `modules/economy.py`.
- **Level**: Value calculated from profile XP, currently by `calculate_level()`.
- **Coin**: Spendable balance stored inside profile economy data.
- **Reward**: XP/coin result awarded at sprint completion; guarded by a sprint/user reward key.
- **Entitlement**: Feature availability decision, used for bot customization.
- **Ephemeral**: Discord response visible only to the interacting user; many menus use this for privacy.
- **Recovery**: Startup process that reconstructs/updates active sprint UI from persisted registry and Discord messages.
- **Runtime data**: JSON files under `data/` that are created or mutated while the bot runs.
- **Legacy**: Compatibility names/paths retained for old settings, command cleanup or sprint join behavior; not automatically a current feature.
